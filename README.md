# Chrome 网页总结翻译插件 - 本地安装使用

## 在 Chrome 中加载插件

1. 打开 Chrome，访问：

   ```
   chrome://extensions/
   ```
2. 右上角开启 **开发者模式**（Developer mode）。
3. 点击 **加载已解压的扩展程序**（Load unpacked）。
4. 选择 `web-summarizer-ext/` 文件夹。
5. 找到插件 → 点击**Details** → 点击**Extension options**。
2. 在 **OpenAI API Key** 中输入自己的 Key。
3. 选择默认语言（如 `中文（简体）`）和总结风格（要点 / 简述 / 详细）。
4. 点击 **Save**。

---

## 使用
1. 打开任意网页（新闻、博客、文档等）。
2. 点击插件图标，选择语言 & 风格（或使用默认设置）。
3. 点击 **Summarize** 按钮。
4. 等待几秒，结果会显示在弹窗下方。

---

## 注意事项

* **付费墙/需登录的网页**：插件只能提取你浏览器当前可见的内容。
* **长文截断**：默认截取前 12000 字符。
* **动态/直播页面**：部分站点提取效果不佳，可在 `content.js` 中添加自定义选择器优化。

---

## 卸载

* 打开 `chrome://extensions/`，找到插件 → 点击 **Remove**。
